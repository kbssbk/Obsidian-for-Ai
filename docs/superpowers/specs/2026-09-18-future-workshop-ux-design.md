# 라이프 OS 미래형 작업실 UX 개편 설계

## 목표
라이프 OS를 모바일·태블릿·PC에서 모두 자연스럽게 사용할 수 있는 반응형 통합 생활 관리 플러그인으로 재설계한다. 시각적 정체성은 어두운 미래형 개발자/엔지니어 작업실을 지향하되, 네온 효과는 상태와 인터랙션 강조에만 사용해 가독성과 접근성을 우선한다.

## 핵심 UX 원칙
1. 라이프 OS 기능은 Obsidian 기본 명령과 즉시 구별되어야 한다.
2. 첫 화면에서 주요 기능으로 1~2번의 탭/클릭 안에 도달해야 한다.
3. 관계는 연락처가 아니라 한 사람과의 인연·약속·후속 행동의 이력으로 다룬다.
4. 약속 데이터는 관계 상세, 타임라인, 달력에서 같은 원본을 재사용한다.
5. 타임라인과 달력은 같은 데이터를 다른 관점으로 보여주는 조회 화면이다.
6. 사용자가 보고 싶은 영역을 다중 선택 필터로 켜고 끌 수 있어야 한다.
7. Markdown/YAML Vault가 계속 단일 원본이며 별도 DB를 권위 저장소로 두지 않는다.
8. 모바일 호환을 위해 Node/Electron 전용 API를 핵심 경로에서 사용하지 않는다.

## 정보 구조
### 빠른 실행 허브
큰 터치 타깃으로 오늘, 빠른 추가, 집중 타이머, 업무, 프로젝트, 약속, 관계, 재정, 타임라인/달력에 접근한다.

### 설명 화면
플러그인 목적, 처음 시작 순서, 추천 사용 흐름, 화면별 역할, 관계/약속 연결, 타임라인/달력 사용, Markdown 저장 방식을 한국어로 설명한다.

### 설정 화면
기본, 오늘, 계획, 집중 타이머, 타임라인, 달력, 관계/약속, 알림, 표시/테마, 데이터/고급으로 그룹화한다. 각 옵션은 효과와 단위를 설명하며 기본값 복원을 제공한다.

## 관계와 약속
기존 person 엔티티는 관계 프로필로 유지한다. 새 appointment 엔티티를 추가한다.

Appointment 필드:
- id
- title
- date
- startTime
- endTime
- location
- purpose
- personIds: string[]
- note
- nextAction
- status: planned | done | cancelled
- path

한 약속에 여러 사람을 연결할 수 있다. 관계 상세 화면은 프로필 정보, 다음 약속, 예정 만남, 지난 만남, 메모/목적, 후속 행동, 해당 사람만의 관계 타임라인을 제공한다. 데이터는 appointment 파일에 한 번만 저장하고 person_id 참조로 파생한다.

## 타임라인과 달력
TimelineSource에 appointment와 focus/time 항목을 포함한다. 필터는 일정, 업무, 목표, 관계, 재정, 집중·시간기록을 다중 선택할 수 있으며 특정 사람을 추가로 선택할 수 있다. 완료 항목 표시 여부도 선택 가능하다.

같은 projection 결과를 달력에서도 사용한다. 월간, 주간, 목록 보기 모드를 제공하며 모바일에서는 목록/주간이 우선적으로 읽기 쉽도록 반응형으로 재배치한다. 날짜를 선택하면 해당 날짜의 이벤트 목록을 바로 확인한다.

## 시각 디자인
- 배경: 차콜/딥 그레이 기반
- 표면: 작업실 콘솔처럼 구분된 패널
- 텍스처: CSS만으로 미세한 그리드/메탈 느낌, 과한 이미지 사용 금지
- 포인트: cyan/violet 계열의 얇은 네온 라인과 glow
- 네온 사용처: 활성 필터, 포커스 타이머, 선택 상태, 현재 날짜, 진행률
- 본문: 높은 명도 대비의 중립색 텍스트
- 모션: 짧고 절제된 transition, prefers-reduced-motion 존중

## 반응형 기준
- 모바일: 1열, 44px 이상 터치 타깃, 가로 스크롤 필터 칩, 중요 행동 우선 배치
- 태블릿: 2열, 목록+상세 조합 허용
- PC: 2~3열, 높은 정보 밀도와 병렬 패널
- 모든 화면은 좁은 폭에서 가로 페이지 스크롤 없이 재배치

## 명령/표현 규칙
모든 사용자 명령은 `라이프 OS · ...` 형식으로 통일한다. `사람 관리`, `사람·돈` 같은 표현을 제거하고 `관계`, `약속`, `재정`으로 분리한다.

## 검증 기준
- 기존 lifeos_type 데이터가 깨지지 않는다.
- appointment 파싱/프로젝션/필터 테스트가 있다.
- 관계별 약속 연결 테스트가 있다.
- 달력 월간/주간 projection 테스트가 있다.
- 한국어 UI 회귀 테스트가 있다.
- 모바일/태블릿/PC CSS breakpoint 규칙이 존재한다.
- npm test와 npm run build가 통과한다.
- 설치 산출물 main.js, manifest.json, styles.css를 생성한다.
