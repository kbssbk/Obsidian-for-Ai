# 라이프 OS for Obsidian

라이프 OS는 오늘 할 일, 업무, 일정, 집중 시간, 관계, 약속, 목표, 재정을 하나의 Obsidian Vault 안에서 연결하는 한국어 생활 관리 플러그인입니다.

핵심 원칙은 **기능은 분리하고 데이터는 통합한다**입니다. Markdown 노트의 YAML frontmatter가 원본이며, 오늘·관계·타임라인·달력·계획·회고 화면은 같은 데이터를 읽어 서로 다른 관점으로 보여줍니다.

## 처음 시작하기

1. `라이프 OS · 빠른 실행`을 열어 전체 기능을 확인합니다.
2. `라이프 OS · 빠른 추가`에서 업무, 일정, 관계 프로필, 약속 등을 입력합니다.
3. `라이프 OS · 오늘`에서 지금 할 한 가지와 다가오는 약속을 확인합니다.
4. `라이프 OS · 집중 타이머`에서 업무와 연결해 집중 시간을 기록합니다.
5. 타임라인과 달력에서 원하는 종류만 골라 전체 흐름을 확인합니다.

## 주요 화면과 명령

- `라이프 OS · 빠른 실행` — 주요 기능을 큰 버튼으로 한 번에 엽니다.
- `라이프 OS · 빠른 추가` — 업무, 일정, 약속, 관계 프로필, 목표, 습관, 재정, 시간 기록을 추가합니다.
- `라이프 OS · 오늘` — 지금 할 한 가지, 오늘 업무, 다가오는 약속, 프로젝트, 생활 신호를 봅니다.
- `라이프 OS · 집중 타이머` — 업무 연결 포모도로/자유 집중, 종료 시 자동 시간 기록.
- `라이프 OS · 업무` — 마감 그룹과 자료 조사/초안/최종 체크포인트.
- `라이프 OS · 프로젝트` — 프로젝트별 수동/자동 진행률.
- `라이프 OS · 관계` — 한 사람과의 예정 약속, 지난 만남, 장소, 목적, 메모, 다음 행동을 관계 타임라인으로 확인합니다.
- `라이프 OS · 타임라인` — 일정, 업무, 목표, 관계, 재정, 집중 기록 중 원하는 항목만 골라 시간순으로 봅니다.
- `라이프 OS · 달력` — 타임라인과 같은 데이터를 월간, 주간, 목록 형태로 봅니다.
- `라이프 OS · 주간 일정` — 7일 일정과 시간 블록.
- `라이프 OS · 계획·습관·회고` — 오늘/내일 계획, 여유 시간, 일정 충돌, 복구, 습관, 분석.
- `라이프 OS · 목표·재정` — 목표 진행과 예산, 수입, 지출, 저축을 각각 확인합니다.
- `라이프 OS · 사용 설명` — 처음 시작 순서와 화면별 역할, 데이터 구조를 자세히 설명합니다.

## 관계와 약속

관계 프로필은 연락처 목록이 아니라 한 사람과의 인연을 모아 보는 기준점입니다. 약속은 별도 `appointment` 노트로 한 번만 저장되고, `person_ids` 배열로 여러 사람과 연결됩니다.

```yaml
---
lifeos_type: appointment
lifeos_id: appointment-example
title: 민수와 저녁
status: planned
date: 2026-09-22
start_time: "19:00"
end_time: "20:30"
location: 수원역
purpose: 이직 상담
person_ids:
  - person-minsu
  - person-jisu
note: 포트폴리오 이야기
next_action: 자료 보내기
---
```

한 약속에 여러 사람을 연결하면 같은 약속이 선택된 사람 모두의 관계 이력에 나타납니다. 데이터는 복제하지 않으므로 약속 노트를 수정하면 관계 화면, 타임라인, 달력에 함께 반영됩니다.

## 타임라인과 달력

타임라인 상단 필터에서 `일정 / 업무 / 목표 / 관계 / 재정 / 집중·시간`을 여러 개 동시에 선택할 수 있습니다. 특정 사람을 선택하면 그 사람과 연결된 관계 기록만 볼 수 있고, 완료 기록 표시 여부도 바꿀 수 있습니다.

달력은 같은 원본 데이터를 사용합니다. 월간, 주간, 목록 보기로 전환할 수 있으며 모바일에서는 좁은 화면에 맞게 달력 정보가 재배치됩니다.

## 집중 타이머와 반복 업무

집중 타이머에서 열린 업무를 선택한 뒤 포모도로 또는 자유 집중을 시작합니다. 진행 중인 세션은 복구용 설정 데이터에 저장되며 `집중 종료 및 기록`을 누르면 `Life OS/Time Logs`에 시간 기록이 생성됩니다.

업무는 `반복 없음 / 매일 / 매주 / 매월`을 지원합니다. 반복 업무 완료 시 마지막 완료일을 남기고 다음 마감으로 이동합니다.

## 설정과 테마

설정 화면은 기본, 오늘·알림, 계획, 집중 타이머, 타임라인·달력, 관계·약속, 표시·테마, 데이터·고급으로 나뉩니다. 각 설정에는 변경 효과와 단위 설명이 있으며 기본값 복원 기능도 제공합니다.

UI는 어두운 미래형 개발자 작업실을 모티브로 합니다. 차콜 배경과 미세한 그리드 질감 위에 cyan/violet 계열의 네온 라인을 활성 상태에만 사용하며, `prefers-reduced-motion`과 큰 터치 타깃을 고려합니다.

## 모바일 · 태블릿 · PC

- 모바일: 1열 중심, 44px 수준의 터치 타깃, 가로 스크롤 필터, 간결한 달력 셀.
- 태블릿: 2열 배치, 관계 목록과 상세를 함께 표시.
- PC: 2~3열 카드와 높은 정보 밀도.

`manifest.json`의 `isDesktopOnly`는 `false`이며 핵심 경로에서 Node/Electron 전용 API를 사용하지 않습니다.

## 데이터 저장 방식

라이프 OS의 원본은 Vault 안 Markdown/YAML 파일입니다. 별도 데이터베이스를 권위 원본으로 두지 않으며 기존 Markdown 노트를 강제로 이동하거나 일괄 변환하지 않습니다. `lifeos_type`이 있는 노트만 라이프 OS 데이터로 읽습니다.

## 시간 관리 원칙과 근거

계획·회고 설계에는 워치타워 온라인 라이브러리의 「시간을 절약하는 20가지 방법」에서 제안하는 우선순위, 과도한 계획 방지, 시간 사용 기록, 집중 시간, 여유 시간, 재충전, 생각 정리, 유연한 재계획 등의 원칙을 제품 기능에 맞게 반영합니다.

공식 원문: https://wol.jw.org/ko/wol/d/r8/lp-ko/102010124

## 설치

GitHub Actions의 `라이프-OS-옵시디언-플러그인` 산출물에는 다음 세 파일이 들어 있습니다.

```text
main.js
manifest.json
styles.css
```

세 파일을 Vault의 `.obsidian/plugins/obsidian-for-ai/` 폴더에 넣은 뒤 Obsidian 커뮤니티 플러그인 설정에서 `라이프 OS`를 활성화합니다.

## 개발/검증

npm install
